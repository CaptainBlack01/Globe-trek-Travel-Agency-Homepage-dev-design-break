# GlobeTrek Travel Agency Website

Welcome to the GlobeTrek Travel Agency website codebase. This project establishes a modern, responsive, and user-friendly experience for travelers looking to book their next adventure.

## 🌟 Key Features

*   **Responsive Homepage**: A fully responsive landing page featuring a hero section, popular destinations, testimonials, and value propositions.
*   **Ticket Booking System**: A dedicated page (`ticket.html`) for users to book tickets.
*   **Real-time Validation**: The booking form includes instant validation for name, email, dates, and ticket quantities to ensure data accuracy.
*   **Semantic HTML5**: Built with accessibility and SEO in mind, using proper semantic tags (`<main>`, `<section>`, `<article>`, etc.).
*   **Modern CSS**: Styled using CSS Variables, Flexbox, Grid, and `rem` units for consistent spacing and typography.
*   **Interactive Mobile Menu**: A fully functional hamburger menu for mobile devices.

## 🛠 Tech Stack

*   **HTML5**: Structure and semantics.
*   **CSS3**: Custom styling, responsive design, and animations.
*   **JavaScript (Vanilla)**: DOM manipulation, form validation, and interactive elements.
*   **Font Awesome**: Icons.

## 📂 File Structure

*   `travel.html`: Main landing page.
*   `ticket.html`: Ticket booking page with form.
*   `travel.css`: Global styles and responsive definitions.
*   `script.js`: Functionality for the navigation menu and form validation.

## 🚀 How to Run

1.  Clone or download the repository.
2.  Open `travel.html` in your web browser.
3.  Navigate to "Book Now" to test the ticket purchase flow.

## 📝 Usage

*   **Navigation**: Use the top links to scroll to specific sections.
*   **Booking**: Click "Book Now" to go to the reservation page. Fill out the form—invalid inputs will show error messages immediately.
*   **Mobile**: Resize the browser to see the mobile menu in action.
